# What the twelve Wasm calls tell you

Send five reports in organ order. Each has 18 private cells, then eight shared corners in slot order. A trit is 0 for failed, 1 for unknown, or 2 for passed. Two different organs report each shared corner. A *seam* is a corner where their reports differ.

The first column names the function in [interface.c](interface.c). The second gives the C symbol it calls and the corresponding definition in [Entry.lean](Entry.lean). The PROVED column names Lean theorems in the `Pentora` namespace. Unqualified theorem references are in [Pentora.lean](Pentora.lean). Some theorems apply before an answer is encoded. For instance, `mem_seams` describes the list that `seamMask` packs into bits. The COMPARED column gives the checks on the shipped file. No theorem in these files establishes that a C wrapper or a Wasm instruction implements its Lean counterpart.

**Packet checks.** For the eight packet-reading Lean entries, `wellFormed` checks for exactly 130 bytes in 0–2. `reportOf` splits them into five reports and `tritOf` decodes each value. A malformed packet, rejected index, or unmet agreement check gives `0xFFFFFFFF`. The handwritten C helper `take` also makes the packet readers return that value after an input error. `owner` and `vertex` read only their arguments. The scripts exercise their valid indices, and for `owner` only selectors 0 and 1.

**Judge comparisons.** All three scripts use seed 20261124. In `check.mjs`, the 400 agreeing bodies cycle through pass biases of 0, 60, 90 and 100 percent. Its five malformed cases are lengths 0, 1, 129 and 131 filled with 2, and length 130 with a 3 at offset 77. In `stamp.mjs`, the 2,000 replacements have a nonpassing true corner. The script checks that the result lies in 1–242 or 256–275. The 500 exact veto comparisons cover 260 single-position objections (0 and 1 at each position), 200 paired private objections, and 40 shared-corner objections. The two limit cases compare the verdict as first one, then both owners hide a failed corner, and as one owner hides a private unknown. In `degraded.mjs`, the 2,000 visible-fault and 2,000 hidden-fault trials check a JavaScript implementation of `go4`. After each repaired packet the script checks all five offline choices in JavaScript. In Degraded.lean, `go_gives_go4` says a five-report stamp implies four-report acceptance for any omitted organ. There is no Wasm export for `go4`.

**What the stamp proves.** In [Stamp.lean](Stamp.lean), `judge_zero_means_go` takes a zero Lean verdict to stamp acceptance. In [StampBytes.lean](StampBytes.lean), `go_means_judge_zero` gives the converse for a valid packet. Also in Stamp.lean, `honest_go` says five truthful views pass exactly when the body passes everywhere. `one_part_cannot_force_go` says a nonpassing corner stops the stamp when the other four reports are truthful about one body. `any_part_can_stop` says one reported nonpass suffices to stop the stamp. `two_owners_can_force` exhibits acceptance with a hidden shared fault, and `private_fault_can_be_hidden` exhibits acceptance with a hidden private fault. These theorems concern the reports and the Lean functions. The comparisons above exercise particular inputs to the compiled bytes.
